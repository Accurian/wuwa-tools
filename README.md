# wuwa-tools

Community calculators for **Wuthering Waves** Echo planning, deployed as a [GitHub Pages](https://pages.github.com/) static site.

| Tool | File |
| --- | --- |
| Echo Budget & Balance Tool | [echo-building-budget.html](echo-building-budget.html) |
| Echo Substat Comparison | [echo-comparison.html](echo-comparison.html) |
| Echo Substats Calculator | [echo-substat-probability.html](echo-substat-probability.html) |

Every tool is a single self-contained HTML file that runs entirely in the browser — no build step, no data collected, no tracking.

## Live site

<https://Accurian.github.io/wuwa-tools/>

## Publishing

The site is served directly from the `main` branch (GitHub Pages → source branch `main`). Push to `main` and the change goes live automatically within a minute or two.
